# Java Algorithms

## Overview
This repository contains various algorithms implemented in Java. The algorithms are organized within the `src` folder, structured to enhance understanding and facilitate usage.

## Folder Structure

### `src`
- **`sorting/`**  
  Contains different sorting algorithms
  - `BubbleSort.java`: Implementation of the Bubble Sort algorithm.
  - `QuickSort.java`: Implementation of the Quick Sort algorithm.
  - `MergeSort.java`: Implementation of the Merge Sort algorithm.

- **`searching/`**  
  Contains various searching algorithms.
  - `BinarySearch.java`: Implementation of the Binary Search algorithm.
  - `LinearSearch.java`: Implementation of the Linear Search algorithm.

- **`dataStructures/`**  
  Implements commonly used data structures.
  - `LinkedList.java`: Implementation of a singly linked list.
  - `Stack.java`: Implementation of a stack data structure.
  - `Queue.java`: Implementation of a queue data structure.

- **`graphs/`**  
  Contains algorithms related to graph theory.
  - `Dijkstra.java`: Implementation of Dijkstra's algorithm for shortest paths.
  - `DFS.java`: Implementation of Depth First Search algorithm.
  - `BFS.java`: Implementation of Breadth First Search algorithm.

## Usage
To use these algorithms, simply import the respective class into your Java project and instantiate the object as required. Each class includes clear method documentation to aid in usage.
